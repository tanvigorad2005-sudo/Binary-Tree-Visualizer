# Binary Tree Visualizer

## About the Project
Binary Tree Visualizer is an interactive web application that helps users understand the structure and working of binary trees through visual representation.

## Features
- Visual representation of binary trees.
- Interactive node creation.
- Easy-to-understand tree structure.
- Simple and user-friendly interface.

## Technologies Used
- HTML
- CSS
- JavaScript

## Purpose
The main purpose of this project is to make learning and understanding binary tree data structures easier through visualization.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
